# 模型、质量框架与边界

本代码耦合LQMD输运、MST初级碎片和本地Fortran GEMINI退激。它不是未经修改的官方GEMINI++分发，也不是各质量模型完整激发态理论的集合。

`m_select.in`选择0=M0、1=FRDM12、2=HFB02、3=KTUY05、4=WS4+RBF、5=本地LDMM候选表。

- mass_framework=1：共同退激结构与M0输运，允许物理程序0–5；基态质量面变化影响母子核质量差、阈值和激发能重建。新手控制器入口只接受1–5，不能用该入口声称已跑0。
- mass_framework=0：兼容旧路径，仅允许0/1，2–5拒绝；这套限制不能外推为框架1也不能运行。旧质量表文档部分默认值已过时，以实际配置及本页为准。
- LDMM第5列作候选总质量面，文件来源未认证；不能将其作为已认证的命名模型来报告。

参考能级密度、平均偶奇回移、壳衰减、yrast和相对势垒处方在统一框架中共用；换质量表不意味着所有微观结构一起替换。详见[统一框架物理定义](../fortran/docs/质量表统一对比.md)。

TARGET_ORIENT_METHOD=2是Haar SO(3)靶核取向。当前MST修复先压缩簇编号再累加属性，冷产物仅对有效核素计数，并检查逐源和逐事件A/Z。已知完整回归范围主要是p+232Th、SURF_COAL=0；真实SURF和含其它非核子体系没有在本发布中完成完整认证。

本发布小样和软件测试证明输入、执行、记账与输出处理能衔接，不是新的实验拟合或全能区验证。旧三种Pa源替换方案及其历史产额未在这里作为通用默认方案发布。不要把2事件的零225Ac输出解释成物理阈值。
