# 统一退激处方中的质量表对比（TASK-012 round-4）

本模式用于比较“在同一套退激处方下，更换重核基态质量面”的效应。各表不再需要提供原生 Emic 或 Meo；能级密度、平均偶奇回移、壳衰减、形变、yrast 和相对基态的裂变/条件鞍点采用共同参考。它不是 HFB02、KTUY05 或 WS4+RBF 各自完整激发态理论的实现。

## 选择开关

`Input file/m_select.in` 使用数据行；空行和以 `!`、`#` 开头的注释行跳过：

```text
2       ! m_select: 0=baseline, 1=FRDM12, 2=HFB02, 3=KTUY05, 4=WS4+RBF, 5=local LDMM
1       ! mass_framework: 0=original, 1=common decay structure
314159  ! comparison seed
```

第二、第三个数据行可省略，分别默认为 0 和 314159。随代码提供的默认仍为 `m_select=0, mass_framework=0`。没有第二行的既有配置保持原行为；统一对比必须把第二行设为 1。第三行的种子用于在同一编译器/程序中复现实验；相同初始种子不意味着各模型经过相同随机分支。

统一模式的模型0采用原输运 `massfrdm.dat` 中的采用质量列，其中包含实验采用值和理论补值，不能称为纯旧FRDM理论质量。模型1..4分别取 FRDM12 Mth、HFB02 Mth、KTUY05 Mcal 和 WS4+RBF 第4列；模型5直接取本地LDMM第5列作为数值辨识的候选总质量过剩，不叠加第4列。原始质量表不改格式、不覆盖。

## 共同物理定义

对每个核素，模式假设参考模型的激发态与形变态随所选基态质量整体平移：

```text
E_i(Z,A;state) = M_i(Z,A) + excitation_ref(Z,A;state)
```

这使同核素内的激发谱和相对势垒固定，而不同核素之间的分离能和Q值改变。当前GEMINI的数据接口同时返回所选总质量和参考鞍点输入，但两者不再被相减来推导所选表的壳修正。

- 基态总质量、母子核质量差、通道阈值和分裂片Q：使用共同生产质量图中的 M_i。
- 壳项：独立从旧参考 total、LD 和平均偶奇项取得，所有组完全相同；不把新旧总质量差当成壳能。
- 条件鞍点中仅查询LD的路径及形变：保留共同参考值。若把LD改成 M_i-C_ref-P，质量差会进入鞍点电荷优化，破坏固定结构的定义，因此不采用。
- 配对回移、mass_option、aden_type、Sierk势垒、yrast及用户参数：保持共同处方和同一输入，不针对某张表重新调参。

这是一种显式的共同经验模型；其结构近似和实验精度需单独评估。有关微观修正依赖能量参照及能级密度处方的说明见 [IAEA RIPL手册第2.2节](https://nds.iaea.org/RIPL-3/handbook/ripl2-feb2005.pdf)。

## 轻核、缺失记录和边界

理论质量只在 `Z>=8 且 N>=8` 的共同研究域内使用。域外轻核、发射粒子及其经验能级对所有组采用同一质量/谱参照。KTUY等表中确实存在的域外记录按共同轻核处方排除，并单独统计，不能报作原表缺项。

域内所选表无理论质量时，使用共同 M0 并明确记录；例如HFB02缺失Mth的记录不得当成零。共同基准也没有总质量时，报出模型、Z、A并停止，不做无说明外推。2n/3n/4n采用相应数量的自由中子质量。

发射粒子的总质量采用共同基态加原有相对能级差，避免母核/残核使用一套质量而DEF常数使用另一套。轻核强制破碎仍属于共同经验谱处理。跨理论域或表覆盖边界的反应是显式混合质量组合，必须结合回退日志解释，不应称为全核图单一原生模型。

用户明确要求按数值判断LDMM字段。在1964个实验采用核素上，第5列直接比较的RMS约2.556 MeV，再加第4列恶化至5.235 MeV。A>=40的8729核七项液滴拟合，原第5列残差3.006 MeV，减第4列后变为1.836 MeV；n/H锚点为8.071/7.289 MeV。这些证据支持第5列已含微观效应，是总质量过剩候选。来源和具体模型参数仍未确认，日志强制输出 `LDMM_COLUMN5_INFERRED_UNVERIFIED_PROVENANCE`；结果应写“本地ldmm.dat第5列候选质量面”，不能称为已认证的特定LDMM模型原生预测。量纲/总质量用途判断为中等置信度，来源认证为低。

可用 `scripts/audit_ldmm_columns.ps1` 重复上述数值核验。即使候选质量的实验偏差较大，它仍是此处敏感性研究的输入，不代表其定量精度已合格；轻核依旧冻结共同M0，不使用该列的d/alpha等明显不同的值。

## 同一批初级事件

统一模式下，LQMD保持M0的输运质量输入，避免不同质量表改变原来的结团选择。先生成一次 `coll.dat` 和 `initangm.dat`，然后用同一份数据分别运行exfrag。anahyp原有计算会按每张表重建基态结合能及E*，不得再手工重复加一次质量差。

对相同初级团簇总能量，未受旧程序负激发截断影响时，有 `E*_i-E*_0=M_0-M_i`。如果人为保持相同E*而换质量，回答的是给定激发条件下的退激比较，应与本模式的初级能量重建区分。

运行助手将各组放在独立新目录，共用输入哈希、配置和种子，避免覆盖已有输出：

```powershell
./scripts/compare_mass_tables.ps1 `
  -SourceDirectory 'D:\Spallation\fortran' `
  -Executable 'D:\path\to\new-exfrag.exe' `
  -OutputDirectory 'D:\Spallation\tmp\mass-compare-run' `
  -Models 0,1,2,3,4,5 -Seed 314159
```

源目录应包含对应的一次输运输出、`Input file/`、`tbl/`、`gdat/`。必须使用本轮源码重新编译的exfrag。输出目录需不存在；助手不重新运行LQMD，不修改源数据，不自动改变事件数和物理参数。正式生产的统计事件数需由研究需要确定。

## 验证范围

测试应覆盖旧路径逐位回归、各表原格式的独立质量核对、共享结构/条件鞍点不变量、阈值与激发能参照、缺项和缓存隔离，以及代表性退激事件。守恒和接口检查不等于散裂产额已经获得实验验证。

本轮已运行 `tests/test_mass_selection.ps1` 与 `tests/test_mass_comparison.ps1`，并用Intel ifx完整编译LQMD/exfrag。默认48080条质量/结构查询逐位回归通过；六组全部质量图的独立原格式核对、共同结构不变量和轻核能量检查通过。Th232在50/100MeV的12个热事件完成并守恒总A/Z；这些单事件不用于产额精度比较。

同源正激发重放夹具中，六组均得到Ra226、Z=88、J=14.70，E*依次为62.02/61.49/62.24/63.81/62.04/65.69MeV，M+E*均约85.68MeV，差别在打印精度内。该夹具只在忽略目录中共同调整了一项分析势能参数以获得正激发，生产输入未改；它验证质量参照重建，不作为真实反应产额。

LDMM在A<=233原生parent上的已覆盖Sn/Sp/Qalpha范围约[-9.54,25.77]/[-8.24,39.39]/[-34.63,12.90]MeV；无daughter质量的组合分别91/131/155项。实际查询这些缺项会停止，未用外推隐藏。负分离能可能表示表中非束缚核，不能自造阈值将其筛掉；具体研究区的通道和回退仍需结合运行日志分析。
