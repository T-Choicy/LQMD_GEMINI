# 质量表选择 m_select（TASK-012）

2026-10-21新增独立的统一对比模式，见[质量表统一对比](质量表统一对比.md)。`m_select.in` 可选第二数据行 `mass_framework=1` 时采用共同退激结构，允许0..5参与对比；第5档是经数值辨识、来源未认证的本地质量面。以下FRDM12原生分解和2..5拒绝规则仅描述 `mass_framework=0` 的兼容路径；默认文件仍保持该路径。

当前支持 `m_select=0`（旧流程）和 `m_select=1`（FRDM12，沿用原 GEMINI 分解约定）。2..5 的原始表和离线格式解析保留，但缺少可靠的分解或字段依据，选择时会说明缺项并退出。逐表物理依据见 [质量表物理兼容性核验](质量表物理兼容性核验.md)。

## 配置

运行目录下 `Input file/m_select.in` 的第一个非空、非注释行设置整数：

```text
1 ! m_select: FRDM12
```

默认文件仍为 0，省略文件也为 0。LQMD 与 exfrag/anahyp 分别读取同一运行目录下的配置。空文件、非整数、越界值或不支持的选项明确退出，不自动降级；旧 LQMD.in/anahyp.in 不增加位置式输入行。

| 值 | 原始文件（Input file/ 下） | 当前行为 |
|---|---|---|
| 0 | 原 massfrdm.dat；GEMINI 原 tbl/gdat | 逐位保持旧流程 |
| 1 | frdm12.dat | 原生核素使用 Mth、Emic、beta2；按旧 GEMINI 约定构造有效平滑质量 |
| 2 | mass-hfb02.dat | 拒绝：缺与总质量对应的、已核实的平滑/微观分解 |
| 3 | KTUY05_m246.dat | 拒绝：Esh 已有，缺 KTUY05 终版平均偶奇项 Meo 的数据或全参数公式 |
| 4 | wsm14.dat | 拒绝：缺 WS4+RBF 对应分解及 RBF 修正的归属说明 |
| 5 | ldmm.dat | 拒绝：第 5 列的物理含义/来源未核实，不能仅凭第 4 列与旧 Emic 相符放行 |

五张表按字节复制自根目录 mass_tables/，没有转换或覆盖旧表。不支持选项的错误包含 `MASS_SELECT_PHYSICS_UNSUPPORTED`、模型名和 `missing=`。

## FRDM12 使用哪些旧数据

原 GEMINI 使用旧 FRDM 的 Mth、Emic 和经验平均偶奇项 P：

```text
mass_exp = Mth
mass_ld  = Mth - Emic - P
shell_corr = mass_exp - mass_ld - P = Emic
```

Emic 是有效微观修正，包含微观配对残差及形变贡献，不是纯壳能。FRDM12 采用同一 Emic 定义，平均偶奇常数 rmac=4.80、h=6.6、W=30 也相同。因此 1 档同时读取新 Mth、新 Emic、新 beta2，继续用原 get_pairing；更新整个记录而非仅更新总质量。

原 get_pairing 采用 Bs=1 的近似；此处保留原统计模型的约定，不宣称 mass_ld 严格等于原生 FRDM12 的完整形变宏观能。Sierk 等唯象势垒、能级密度公式和参数保持原方案，其经 getmass 的总质量/平滑质量输入共同更新。

## 覆盖与旧表回退

- 原生记录：LQMD 的 READ_XBIN、anahyp 的 XBIN 和 GEMINI 的总质量均采用同一 Mth。GEMINI 的有效平滑项和 beta2 来自上述同一新记录；查询优先于旧 Z/A 范围限制。
- 衰变子核不在 FRDM12 中：GEMINI 完整沿用既有 TF/FRDM1992/解析式的 total、LD、beta 记录，不混入输运旧实验质量。输运侧非原生数组项保持原值。
- **初始激发残核必须在 FRDM12 内。** 旧输运 massfrdm.dat 首列质量与 GEMINI 旧 TF 总质量并不总相等；例如 d 约为 13.136 与 17.92 MeV。为防同一激发能跨基准误用，1 档在 fusion 初始源初始化之前检查记录，缺失时以 `MASS_SELECT_SOURCE_UNCOVERED` 报出 Z、A 并停止。
- 不自动提高 MCFR、改激发能或换算一个未定义的质量基准。FRDM12 从 Z,N>=8 开始；C/N 等表外初始源会触发覆盖错误。这不妨碍它们作为衰变链中的旧表子核处理。
- 上述回退是明确的混合模型边界；应检查边界附近的 Sn、Sp 和 Q 值，不能声称整个核素范围都来自单一 FRDM12。

## 模块与原程序的关系

mass_select.f 是 MODULE mass_selection，没有独立 PROGRAM。编译 LQMD 时，经 main.f 的 INCLUDE 编入；编译 exfrag 时，经 GEMMOD.f 的 INCLUDE 编入。USE 提供接口，两个可执行程序各自持有一份模块状态，不通过中间转换表或跨进程共享内存传质量。

main/anahyp 原数组通过过程调用更新；GEMINI 的 getmass 返回总质量、有效平滑项和形变，所有已追踪的运行时质量查询均走它。生产缓存与离线检查缓存分开，离线检查其他模型不能污染 FRDM12 运行。

旧 getmass 的 mass_exp/mass_ld 实际是总质量/平滑质量，不是 Mexp/Mth 一对。旧实验列覆盖分支已被注释；新 FRDM12 同样选择理论 Mth，不能把实验列误填到第二路输出。

## 验证

```powershell
./tests/test_mass_selection.ps1
```

使用已有 gfortran、Git，产物位于忽略目录 tmp/task012/tests/。测试覆盖 0 档逐位回归、FRDM12 全部原生记录的总质量/Emic/beta2/平滑项、单独 LD 查询、整套旧回退、初始源覆盖、离线缓存隔离，以及 2..5 的准确拒绝。其他模型的离线原格式检查输出 MASS_TABLE_INSPECTION_ONLY；读数正确不等于物理移植完成。

另用 Intel ifx 完整编译 LQMD/exfrag，运行代表性事件并检查模型边界。具体执行结果记录于 TASK-012 自检；这些验证不认证新模型的产额预测精度。
