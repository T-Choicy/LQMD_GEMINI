# exfrag 参数手册：输入、联动与调参

配套：[工程说明书](exfrag_%E5%B7%A5%E7%A8%8B%E4%BB%A3%E7%A0%81%E8%AF%B4%E6%98%8E%E4%B9%A6.md)｜[源码接口索引](exfrag_%E6%BA%90%E7%A0%81%E7%B4%A2%E5%BC%95.md)｜[验证与已知问题](exfrag_%E9%AA%8C%E8%AF%81%E4%B8%8E%E5%B7%B2%E7%9F%A5%E9%97%AE%E9%A2%98.md)。基于 2026-09-05 的当前源码。

理解参数的物理影响，可先看[对照 Charity（2008）的公式精讲](exfrag_%E5%85%AC%E5%BC%8F%E7%B2%BE%E8%AE%B2_%E5%AF%B9%E7%85%A7Charity2008.md)，再用[交互教学计算器](exfrag_%E5%85%AC%E5%BC%8F%E4%BA%A4%E4%BA%92%E6%95%99%E5%AD%A6.html)观察a、热能、势垒和部分宽度的变化。文献中的GEMINI++拟合数值不自动等于本地Fortran的默认参数。

## 1. 配置不是键值文件

实际输入只有 [Input file/anahyp.in](../Input%20file/anahyp.in)。以下“行”均为该文件的物理行号，**样例值不等于推荐值或自动默认值**。删除标题、增加空行、交换行序都会改变后续读取。各行尾部多余文字虽可因接收项已满足而被忽略，也不应据此改列数。

第 1、5、11、15、18、23、25、33、35、38、40、45、46、55、64 行是被空 `READ` 消费的标题行。数值记录由 [anahyp:283](../anahyp.f#L283) 与 [INPUT_ANA:10182](../GEMMOD.f#L10182) 顺序消费，总计 67 行。文件后面的内容不会自动成为新配置。

类型：I=整数，R=实数，L=逻辑 `.true./.false.`。主程序没有 `IMPLICIT NONE`，I–N 开头默认整数，其余默认实数；有显式声明时以声明为准。所以一些“开关”实际上是实数。为保持当前分支判定，仍填精确的 0 或 1，不填近似值。

## 2. 批次、事件与并合

| 行 | 参数 / 类型 / 样例 | 实际作用 | 如何设置与核对 |
|---:|---|---|---|
| 2 | `NTH_RUN` I = 0 | 0 从当前目录读；非零从 `results/` 读，并将部分输出写入 `anaNNN/`，部分归一化走批次分支 | 新案例先用 0；非零不是断点续算。限三位非负编号，预先建输出目录；合并时核对各文件分母 |
| 3 | `NTH_NOH` I = 0 | 生成四位输出后缀，过程中该变量被十进制拆分改写 | 仅文件标识，不控制物理抽样；使用 0–9999，另存原始配置 |
| 4 | `NRMIN,NRMAX` I = 1,10000 | **仅NTH_RUN≠0时**，在读完时间片后按外层事件编号L1判断范围与退出 | 单次模式不按这两个数筛选。批次多时间片跳过可能未消费本事件剩余记录；先用单时间片验证。不要把L1与NNEVENT混同 |
| 6 | `npar` I = 10000 | 最外层尝试读取的事件数 | 必须匹配 coll 实际事件数。没有健壮 EOF 检查；统计误差靠增加独立输运事件降低 |
| 7 | `X00CUT` R = 8.5 fm | 面积因子 `π X00CUT² × 10` mb | 源码不实施 b 截断；必须与输入事件的真实抽样面积一致。b 按面积均匀采样与按 b 均匀采样不能混同 |
| 8 | `kktot,kkmin,kkmax` I = 1,1,1 | 每事件待读时间片总数、处理时间片序号范围 | `1<=kkmin<=kkmax<=kktot`；与 coll 输出顺序严格对应。这里是时间片序号，不是 fm/c；物理时刻来自记录 `k*dt` |
| 9 | `rr0` R = 3.5 fm | 粒子对相对距离上限，后续 RMS 限制也使用它 | 增大使初级簇更易连接，但完整算法并非仅 pairwise 图连通；同步检查碎片 A/Z、多重数、成员守恒 |
| 9 | `pp0` R = 0.2 GeV/c | 粒子对相对动量上限；额外 RMS 动量判据也使用它 | 与 rr0 联合扫描；输入动量是 GeV/c，不能填 200。扩大动量窗口通常并入更多非平衡核子，E* 和退激随之变化 |
| 10 | `READMESON` R = 0 | 每条核子记录后是否额外读取一条介子记录 | 必须与输运文件写法一致；不能仅因“想研究介子”而开。记录布局错一行后整文件错位 |
| 12 | `COLM` I = 1 | 进入并合及包在其中的热簇/退激分析 | 当前 GEMINI 主流程嵌在 COLM 分支；`COLM=0,GEMINI=1` 不是独立 GEMINI 模式 |
| 12 | `GEMINI` I = 1 | 是否对满足门槛的热簇调用统计退激 | 对比 0/1 可区分初级识别与退激影响，但须对同一输入比较，且先解决初始化/索引问题 |
| 13 | `ANGM_DEC` I = 1 | 读取 initangm，计算用于退激的残余角动量 | 打开需要匹配事件的初始角动量文件；关闭后 L 没有可靠赋零，不可当作已实现的 J=0 模式 |
| 13 | `ANGM_LIGHT` I = 10 | 用 `ICL > ANGM_LIGHT` 判定重簇数，决定是否满足单重残余角动量计算前提 | 是质量 A 阈值，不是电荷 Z；实际轨道扣除遍历全部有效簇。多重簇分支存在跳过清零的问题，调阈值不能代替修复 |
| 13 | `TESTANG` I = 0 | 打印角动量诊断后执行 PAUSE | 核对初始 J、扣除项和剩余 J；打印的全局和遍历到 MG，需防止未填充槽参与。会暂停，不适合无人值守批次 |
| 14 | `SURF_COAL` I = 0 | 使用额外表面发射记录及核子标记 | 必须有匹配的 SURF_COAL.dat 与扩展 coll 格式；当前含测试性硬编码，不能作为通用物理选项直接标定 |
| 16 | `MCFR` I = 5 | 以 **Z>MCFR** 决定完整内部能量重建、Mul_MCFR 计数和 GEMINI 资格；Z≤MCFR 直接按基态能量令 E*=0 | 是电荷阈值，不是质量阈值，也不只是统计分类参数。降低会让更多轻核进入重建/退激，须检查轻核模型适用性；它不直接改变 MST 的 rr0/pp0 |
| 17 | `TESTEX` I = 0 | 激发能测试/打印分支 | 相关参考准备代码已被注释，MASS1 等未保证有效；不是通过开关即可获得的严格能量单元测试 |
| 17 | `OUTENE` R = 0 | 非 TESTEX 分支下的能量明细输出 | 用于定位 T、势能及结合能；部分旧打印项从未进入总能量，读输出须结合主文第 6 节 |

并合参数改变的是**热初态**。任何用产物谱反推 rr0/pp0 的工作，都要同时保存未退激的簇分布，避免把后续 GEMINI 参数变化误解释成并合物理。

## 3. 激发能门槛、诊断与时间演化

| 行 | 参数 / 类型 / 样例 | 实际作用与单位 | 调整方法 / 约束 |
|---:|---|---|---|
| 19 | `DECNEXC1` R = 2.0 MeV | GEMINI 调用的下限，与整数 nexc 比较 | 是总 E*，不是 E*/A；先核对从浮点 E* 到整数 NEXC 的转换。提高会保留更多未退激簇 |
| 19 | `DECNEXC2` R = 1000.0 MeV | 送入GEMINI的总激发能裁剪上限 | `NEXC>DECNEXC2`时执行`NEXC=DECNEXC2`，并不拒绝该簇。上限通常应高于下限；保存原始EXCEN、截断后NEXC与被裁掉的能量，不能把裁剪当能量守恒处理 |
| 19 | `DECIZ` I = 100 | 可退激核的最高 Z | 不代表所有表和势垒均覆盖该 Z；不能独自调大来扩展重核能力 |
| 20 | `PRINTCLKIN` R = 0 | 平动动能诊断 | 可辅助排查参考系；CLKIN 并不总是按输出动量所在参考系更新 |
| 21 | `PRINTDEC` I = 0 | 打印退激前后的粒子信息 | 从少量事件开启；大样本严重增加日志量 |
| 21 | `Z11,Z22` I = 1,55 | PRINTDEC 诊断选择的电荷范围 | 仅改变诊断范围，不是产物物理截断 |
| 22 | `gemini_in_out` I = 1 | 写 `GEMINI_INPUT.dat` 的 MST 最大团簇诊断，并写 `FRAG_CORR.dat` 的对应最大质量有效末态核 | 每时间片仅取 `maxloc(ICL)` 源；末态候选要求 `Z>=0,A>0`，取最大 A，并列保留首个 `frag` 下标；不与全量 `CNPCS_COLD` 对齐，使用 units 182、184 |
| 24 | `ECHECK` I = 0 | 写 E_SH.out 的若干能量量 | 占用 unit 19，与 TEELECS 冲突；前后量的物理口径不同，不能直接把差值当完整能量守恒误差 |
| 26 | `TEAE` I = 1 | 最大残余核的 E*/A、A、多重数随时间统计；填充 EXCCROSS 所用数组 | 需要一致时间网格与有效最大簇；物理时刻是 k×dt。要 EXCCROSS 有数据必须考虑此依赖 |
| 27 | `EXCCROSS` R = 1 | 打开 EXCCROSS 输出，包括总 E* 直方图及按质量累加的激发能 | 不是名为 EXCCROSS1 的开关。第二段标签 mb 与实算量不符，见主文归一化 |
| 27 | `TEAMUL` R = 1 | TEAE 末尾输出三类事件数及组内平均时间、E*/A、最大质量、重簇多重数 | 写 unit 6，常与标准输出共用；须检查文件有无 PRINT 日志混入 |
| 28 | `EX1DOWN,EX1UP` R = 0,1.5 MeV/u | 最大残余 E*/A 峰值的第一分类区间 `[low,up)` | 是分类门槛，不修改 E*；与其它区间不重叠、无意外空隙 |
| 29 | `EX2DOWN,EX2UP` R = 1.5,3 MeV/u | 第二分类区间 `[low,up)` | 若区间重叠，后续独立 IF 可覆盖前面的 FLAGEXC |
| 30 | `EX3DOWN` R = 3 MeV/u | 第三类下限，无上限 | 只对尚未判为多碎片的时间历史更新 MAXEXC，因此分类样本与所有事件并不等价 |
| 31 | `EXPNT` R = 0 fm/c | 只有 `k*dt >= EXPNT` 才更新最大激发能 | 排除早期瞬态时调整；与选定 kkmin/kkmax 和真实时间记录一致 |
| 32 | `PRTEX_WRTPHAS` R = 0 | TEAE 内交互选择事件类别和输出时刻，写 WRTPHAS.dat | 会 `READ(*,*)` 等待用户输入，不适合无人值守批处理；轨迹数组下标直接使用 k，容量不是任意长 |

### 4.1 辅助输入的最小契约

主文第 3、10 节给出路径和输出量。读取辅助文件时须同时核对**每条 READ 的接收项**与数组容量：

| 文件 | 控制变量与约束 | 首先检查 |
|---|---|---|
| `DDCSS_LNKED_in.in` | `NSPECIES<=30`，每核素 label,Z,N；`NANGLE<=100`，角度记录为度数、Spacing factor | Spacing factor乘在输出截面上，样例含1、0.1、0.01、0.001用于错开绘图曲线。真正累计用dkin=1 MeV、dthe=0.1 rad；文件后面的Split/BinN未读取 |
| `IPCS_in.in` | `IPCSMAX=100` 个元素容量；每记录 label,Z | 输出中子数轴 0..200；写错 Z 会得到错误或空的选择 |
| `ELEKED_in.in` | 接收 label,Z,N；最多 crossmax | 自带记录只有 label,Z，与第三列接收项不一致 |
| `TEELECS_in.in` | 最多 TEAMAX=10 个核素，label,Z,N | 热/冷计数表第一维 300，实际访问的 k/IT 与记录时间均需校验 |
| `initangm.dat` | 每事件首时间片读取`L12,Jx,Jy,Jz`，后三者以ℏ为单位 | 主程序只对新计算的`r×p`乘5.067731，不再对输入J做相同转换；错一事件会影响所有后续退激J |
| `SURF_COAL.dat` | 最多 20 项，(Z,A)=(0,0) 终止 | 不是仅有核素名称的列表；每簇还有能量、动量和角动量项及关联核子标志 |

辅助文件内的标题行和数目字段也由空 READ/顺序 READ 消费，不能把这张契约表当作可直接粘贴的完整文件模板。

## 5. 激发能重建的相互作用参数

公式、粒子对计数和单位转换见主文第 6 节。以下参数应优先保持与生成 coll.dat 的输运模型一致，不能独立拟合到漂亮的冷碎片分布后仍声称是同一个 Hamiltonian。

| 行 | 参数 / 类型 / 样例 | 控制项 | 改动的直接数学效果 |
|---:|---|---|---|
| 41 | `alpha` R = −0.2825 GeV | `α/2 Σρ_i/ρ0`，二体 Skyrme | 增大 α（变得不那么负）抬高内部能量 |
| 41 | `batat` R = 0.2300 GeV | `β/(γ+1) Σ(ρ_i/ρ0)^γ` | 源码变量拼写就是 batat；增大 β 提高此正贡献 |
| 41 | `gmmat` R = 1.16667 | 上式 γ，密度指数 | 同时改变分母和密度幂，不是单纯按比例放大；必须联合检查所对应 EOS |
| 42 | `gsur` R = 0.0120 GeV·fm² | 梯度表面项 | 对每对的 Laplacian 核有正有负，不能保证所有碎片 E* 同方向改变 |
| 42 | `gtau11` R = 0.0097 GeV | `gτ Σ(ρ_i/ρ0)^η` | 影响密度相关有效质量/动能近似项；不是核子真实静质量 |
| 42 | `eta11` R = 1.66667 | 上式 η | 主要改变不同密度区域的相对权重 |
| 43 | `gsym` R = −0.00270 GeV·fm² | 表面对称梯度项 | 与 `isy(i)*isy(j)` 及空间重叠共同决定符号，须明确 isy convention |
| 43 | `symm` R = 0.0320 GeV | 体对称项的系数 | 对中子过剩碎片 E* 和同位素比尤其敏感；不能脱离质量表/对称能一起解释 |
| 44 | `momp` I = 0 | 是否计算 MDI 动量相关项 | 开启采用源码内部固定系数及 pp/nn、pn 配对；不从输入同时读取一整套 MDI 系数 |

`rho0=0.16 fm⁻³`、`sl(i)` 的质量依赖波包宽度、`ℏc`、Coulomb 系数、MDI 强度与对数参数均在源码固定，**并不因为改上表而自动重新标定**。特别要区分 coll 头部的 `al`、`sl(i)` 返回的 L 和二核子重叠的 `L_i+L_j`。

## 6. GEMINI 尾部参数

所有参数先由 INPUT_ANA 存入 `_ANA` 变量，再在每个热簇的 `input(IZ,IN,NEXC,-1.)` 中拷入全局 `para`。以下类型来自 gemsub/gem_kind 声明，约束来自 [input](../GEMMOD.f#L10568)。

| 行 | 参数 / 类型 / 样例 | 作用与适用分支 | 如何调整 |
|---:|---|---|---|
| 47 | `imf_option` I = 2 | 0 无 IMF/裂变，1 对称裂变宽度，2 全不对称二体通道；代码另有 3 路径 | 这是模型选择。比较 0/1/2 应同时检查质量、电荷分布和轻粒子补偿；3 不在样例说明内，不作为已验证推荐选项 |
| 48 | `t_delay` R = 20，单位 10⁻²¹ s | 裂变延迟时间尺度 | 需在启用 time_wise 的路径内才按时间竞争起作用；mode1 强制 time_wise=false。增大通常推迟裂变，但最终效应依赖竞争蒸发 |
| 49 | `sig_delay` R = 1 | 延迟对质量不对称度的控制参数 | 不是无条件的高斯时间误差。精确进入的 η 公式见主文第 8.16 节；设 0 会关闭 time_wise |
| 50 | `sharp_delay` L = true | true：延迟前禁用、之后开放；false：渐增宽度分支 | 改的是时间核形状，不只是性能选项；需比较早期粒子蒸发与裂变竞争 |
| 51 | `Z_imf_min` I = 3 | 轻粒子蒸发与 IMF 的电荷分界 | 输入被截到 3..5；=3 对应 A_cut 至少 8，否则至少 12。提高到 4/5 改变两套理论的责任范围 |
| 52 | `Kramer` R = 0 | 裂变宽度抑制/耗散参数 | 0 不加对应修正；非 0/1 与 imf>=2 组合会 STOP；并非在所有分支中“0 就是无裂变”。使用时核对源码修正函数 |
| 53 | `lestone` L = false | 对称裂变中的倾斜模/自旋自由度修正 | 仅在相应 fission_width 分支生效；需与 J、旋转惯量联合判断 |

### 6.1 参数联动与隐藏设置

anahyp: input(IZ, IN, NEXC, -1.)

`R_num=100` 不代表当前接口为每个热簇实际模拟 100 次；主程序每个符合条件的簇只 `event` 一次。`fusion(L,cn)` 的 L 实参决定自旋，不受这里 Lmin/Lmax=0 自动约束。当前没有由 anahyp.in 提供的“固定随机种子”配置。

不要将独立 GEMINI `test.inp` 的字段添加到本文件尾部来尝试控制这些设置；必须通过经审查的接口改动才能改变。

### 6.2 aden_type 的全部 23 个公式

源码：[get_little_a](../GEMMOD.f#L2873)。记 A=质量数、Z=电荷数、U=进入 SELECT CASE 前已经做配对/壳修正的能量、s=表面形状因子 surf、c=aden_0、k0=`aden_k0`、kinf=`aden_kinf`、J=角动量、`Zβ=A/(1.98+0.0155 A^(2/3))`。本表先给未乘实参 aa_scale 的 a；最后统一 `a*=aa_scale`，`S=2√(aU)`。小数指数按源码保留，不强行改为精确分数。

| aden_type | 当前实现的 a | c 的含义 / 说明 |
|---:|---|---|
| 0 | `A/c` | 通常的 A/a 常数 |
| −1 | `A/14.61 × (1+4s/A^(1/3))` | c 不使用 |
| −2 | `0.073A + 0.095s A^(2/3)` | c 不使用 |

| −6 | 见下方迭代 | 同时改变 U；c 不使用 |
| −7 | `A/11.5+0.117s A^0.66666 exp(−5U/(3A))` | c 不使用 |
| −8 | `A/15+0.34s A^0.66666 exp(−5U/(3A))` | c 不使用 |

| −10 | `A/(7+cU/A)` | 同上 |

| −14 | `Z/c` | 质子数比例式；Z=0时会为0 |

| −21 | `A/[8+c(U/A)J/50]` | 自旋相关能量项 |
| −22 | `A/[kinf−(kinf−k0) exp(−0.00493 exp(0.0332A)U/A)]` | k0/kinf 取输入第67/68项；U 为背移后的 U。默认7.3→12时，对 U≥0 的 k 单调升高 |

mode −6 的代码顺序不能压成一个独立 a(U) 常数：

```text
a1=(1.6 A+1.8 A^(2/3))/15.5
a2=0.5 A/15.5
Esym=0
重复2次：
  u0=(U−Esym)/(441 A^(1/3))
  f=1−exp(−8u0)
  u1=u0 A/(a1−a2 f)
  a=a1−a2[1−exp(−u1)]
  Esym=0.82247(1/a−1/a1)(A−2Z)²
U=U−Esym
```

不同模式代表不同经验模型，不能把 0,−1,−2… 当作连续的拟合刻度。要比较模型，应先固定数据、质量/壳修正、初态 E*、J，检查各核与能量范围内 a>0、U>0，然后比较完整观测量。

## 8. 可复用的调参流程

### 8.1 先建立可以比较的基线

1. 固定同一份 coll.dat 和匹配的质量/角动量文件；记录输入哈希、抽样方式、束能、冻结时刻及编译器。
2. 先做一个时间片的读取和并合检查，统计 `ΣA,ΣZ`、成员唯一性、热点簇数、最大簇、E*裁剪比例。源码问题尚未修复时，基线只能标为诊断基线。
3. 对少量明确的 `(A,Z,E*,J)` 独立检查 GEMINI：质量/电荷守恒、终止条件、表加载和随机控制。
4. 再连接全链路；同时保留 HOT 和 COLD、退激调用次数、被门槛跳过的 A/Z/E* 分布。
5. 用有独立物理预期的案例验证截面面积与能谱积分。程序正常退出并不能完成这一项。

### 8.2 一次只改变一个物理层

| 层次 | 可执行的敏感性设计 | 必须同时观察的量 |
|---|---|---|
| 冻结时间 | 使用输运实际输出的若干相邻冻结快照，先分文件单时间片分析 | 最大簇A、自由核子数、热E*/A是否稳定 |
| 并合 | 围绕样例做局部 rr0×pp0 网格，例如 rr0=3.0/3.5/4.0、pp0=0.18/0.20/0.22，仅作数值敏感性例子 | 热簇分布、成员守恒、重簇连接变化和 E* 尾部；这些数值不构成已标定的物理推荐 |
| 能量重建 | 先对齐输运的整套 α/β/γ/表面/对称参数，再逐项核对能量分量 | 接近冷核的 E*、质量表扣除、MeV/GeV转换、裁剪为0的比例 |
| 角动量 | 固定初态，核对初始J−逸出轨道角动量与送入 fusion 的 L | 所有热簇J、旋转能与可用热能、负/未定义数值 |
| 能级密度 | mode0 对 c 做小范围灵敏度扫描，或明确比较离散模型 | 轻粒子多重数、残余质量、IMF/裂变率及能谱；同时固定初始 E* |
| 裂变 | 先选定 mode1/2，再调该路径真正消费的参数 | 鞍点U、势垒、宽度分解、延迟蒸发与质量不对称；mode2 可扫描 b_scale，但 a_scale 仍不生效 |
| 数值精度 | 对 threshold、能量积分格和缓存做收敛检查 | 有物理意义的积分量及尾部，连同耗时；不要用收敛阈值拟合实验 |
| 输出 | 固定物理样本后改变分箱/DIFF选择 | 入选率、谱积分、边界漏计、面积权重与误差条 |

### 8.3 统计量与扫描记录

理想独立等权事件、单格计数 C、面积 S 下，估计截面 `σ=S C/N`；稀疏格的粗略 Poisson 误差为 `S√C/N`。同事件多个相关产物、一个热核重复退激、带权事件或比值，都不能直接套用这个误差公式。当前输出的既有误差实现还须逐项检查。

建议每个扫描点单独目录，至少保存：完整输入、源码哈希、编译器和选项、输运与退激随机策略、事件/时间片实际计数、成功/跳过簇数、HOT/COLD守恒汇总、谱积分和运行日志。当前程序没有完整导出这些信息；要长期生产使用，应先把相关诊断作为单独实现任务审查。

### 8.4 按症状回到正确层次

| 症状 | 优先排查 | 不应先做的调参 |
|---|---|---|
| 开始即 EOF | unit18冲突、标题行、记录列数、事件数 | 增大激发能上限 |
| 碎片核子总数变少 | IC/ICL重映射、回填索引、特殊粒子过滤 | 增大rr0企图“补回来” |
| COLD 保留高激发重核 | GEMINI调用门槛、COLM、Z范围、整数E* | 先改质量表或把所有冷产物视为蒸发残余 |
| 改 a_scale/b_scale 完全没反应 | `a_scale` 在 mode2 的已知死路径；`b_scale` 是否为0/1或条件势垒非正；实际调用路径 | 继续扩大参数变化范围 |
| 后续事件结果依顺序漂移 | 重复CDF初始化、残留全局状态、种子控制 | 归因于随机误差后直接加事件数 |
| 截面整体偏固定倍数 | b抽样面积、X00CUT、NEVENT/NNEVENT、时间片重复、批次分母 | 改核相互作用强度 |
| 角谱异常但产额正常 | rad/deg、整数角查询、回填p和CLKIN参考系、DIFF门 | 先改变裂变延迟 |

当前输入不能通过某一个“推荐参数组合”消除已确认的代码缺陷。正确调参顺序是明确数据契约、确认分支有效性、验证数值与守恒，再做物理标定。
