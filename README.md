# LQMD_GEMINI v0.0.0

Historical source archive of the user-supplied legacy folder, including source edits present at archival time.

This independent snapshot does not replace or merge into main, v0.1.0 or v0.1.1.

## Contents

Legacy Fortran sources, build project, input templates, initialization data, gdat/tbl and mass tables. PROVENANCE.json lists payload sizes and SHA-256 hashes. Original payload bytes are preserved.

Excluded: nested Git metadata, editor/assistant settings, internal plans, build products, generated runtime outputs (including Sqr_pot.dat), and param_test experiments/results. The original folder is unchanged.

## Validation

Payload bytes and Git blobs were compared against source files. Compilation and simulation were not performed. This archive is not a newly certified physics release.
