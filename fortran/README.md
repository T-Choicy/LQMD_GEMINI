# LQMD 源代码阅读顺序（Markdown版）

---

## 第一阶段：程序入口与基础设施（先理解"外部设定"）

| 顺序 | 子程序 | 行号 | 看什么 |
| :---: | :--- | :---: | :--- |
| 1 | program LQMDini | 6–600 | 主程序：读入所有 LQMDin.in 参数，设置 COMMON 变量，理解所有开关的含义（`initi`, `iflag5`, `momp`, `irad` 等），然后根据 `initi` 分叉到 `init0` 或 `init2` |
| 2 | width0 | 5337 | 高斯波包宽度 `width` 的计算，只有几行，`width = (c1*A^(1/3)+c2)^2` |
| 3 | initp | 1047 | Pauli 阻塞参数 (`radn`, `padn`, `const`)，初始化时不一定直接调用，但 `avene` 和 Pauli 子程序依赖它们 |

---

## 第二阶段：核心初始化（`initi=0` 的主路径）

| 顺序 | 子程序 | 行号 | 看什么 |
| :---: | :--- | :---: | :--- |
| 4 | init0 | 2127 | 总控。不到40行，逻辑极其清晰：`pfc = pfc0` → 循环 `call init1` → `call prot` → `call avene` 算结合能 → 偏离目标就调 `pfc` 重来。先把这段吃透。 |
| 5 | RADRI | 5248 | 弹核均方根半径初始化。用硬球采样 + 表面扩散 + Pauli 排斥迭代，产出一组满足 RMS0N/RMS0P 的核子径向位置数组 `rrrr(1..npr)`，供 `init1` 使用 |
| 6 | init1 | 1580 | 整个程序最长、最核心的子程序（~550行）。分四段读：① 弹核坐标采样（变形+Pauli排斥）② 靶核坐标采样 ③ `densitn` 算局域密度 ④ 动量空间费米球采样 + Pauli 排斥 + `delrot` 去转动 + CM 归零 + 束流动量。然后在末尾有一段摩擦冷却的半步推进（`dt=dt/2` 推进坐标） |

---

## 第三阶段：密度与能量（`init0` 的"判据"）

| 顺序 | 子程序 | 行号 | 看什么 |
| :---: | :--- | :---: | :--- |
| 7 | densitn | 2274 | 坐标空间密度。用自洽宽度 `sl(i)+sl(j)` 计算每个核子处的局域密度 `dens1(i)` 和总密度 `denstl(i)` |
| 8 | densim | 2301 | 动量空间密度（用于 Pauli 势），与 `densitn` 对称 |
| 9 | prot | 2388 | 单步传播（计算力、更新动量和坐标），在 `init0` 的迭代中被调用，让核子"弛豫"半时间步以得到更真实的势能 |
| 10 | avene | 4525 | 第二大子程序（~650行）。计算总能量 = 动能 + Skyrme势 + Coulomb + 对称能 + 表面能 + 动量相关势 + Pauli势 + 壳修正。这是 `init0` 迭代的"标尺"，也是理解整个能量泛函的地方 |

---

## 第四阶段：`avene` 的依赖函数

| 顺序 | 子程序 | 行号 | 看什么 |
| :---: | :--- | :---: | :--- |
| 11 | coulgn | 4420 | Coulomb 能计算（直接项+交换项） |
| 12 | FS, GS | 5565, 5584 | 壳修正的 F/G 函数 |
| 13 | SWITCH | 5603 | 平滑开关：弹核/靶核 → 复合核的半径和壳修正平滑过渡 |
| 14 | fmlog, fmnp0 | 5670, 5688 | 费米积分（零温/有限温），为 MDI 动量相关势提供解析表达式 |
| 15 | xmoms, xpart | 5702, 5983 | MDI 动量空间数值积分。`xpart` 分段调用 `xmoms`，`xmoms` 调用 `flow`/`fupp`/`funsm` 族做费米球积分。这部分比较数学，知道输入输出即可，不用逐行啃 |

## 第五阶段：旋转处理与弛豫

| 顺序 | 子程序 | 行号 | 看什么 |
| :---: | :--- | :---: | :--- |
| 16 | delrot | 2168 | 计算整体角动量，通过惯性张量对角化求出旋转角速度 ω，再从每个核子的动量中减去刚性转动分量 |

## 第六阶段：替代路径（`initi=1`）

| 顺序 | 子程序 | 行号 | 看什么 |
| :---: | :--- | :---: | :--- |
| 17 | init2 | 1333 | 从文件读预生成的弹核/靶核相空间，做 CM 平移 + Euler 旋转。调用 `coulgn` 计算初始 Coulomb 场 |

## 一句话总结

**最佳阅读路径**：`program LQMDini`（参数理解）→ `init0`（控制流）→ `init1`（核心采样）→ `avene`（能量判据）→ `xmoms`/`xpart` 等（MDI 数学细节）。其余按需查阅。
