# 什么上传，什么单独保存

| 内容 | 放在哪里 | 原因 |
|---|---|---|
| Fortran源码、构建/调度/解析脚本、文档、版本与测试 | Git | 可审查、可定位版本 |
| 必要输入模板、pini/tini初始化数据、tbl/gdat、质量表及来源说明 | Git，保持数值字节 | 新克隆能运行，质量基准可追溯 |
| 小型合成测试夹具、示例配置 | Git | 不依赖课题组私有计算目录 |
| coll/initangm、CNPCS、实验CSV、图片和完整日志 | runs或课题组数据存储 | 研究结果随实验归档，避免污染代码历史 |
| exe/obj/mod、缓存、虚拟环境、临时编译/测试 | 本机生成，不进Git | 与平台或一次验证相关 |
| 密码、令牌、SSH私钥、环境凭据 | 凭据管理器，绝不进Git | 不是运行输入 |
| 旧聊天、内部任务记录、依赖历史绝对路径的试验脚本 | 原研究工作区 | 不作为通用公开接口发布 |

仓库不是完整研究数据备份。正式结果应有实验ID、代码标签/提交、输入/表/程序哈希和运行清单；大型数据另存并在论文/课题组记录提供访问方式。未做匿名化或未获公开许可的实验数据不要附在issue中。

原始数值表禁止格式化、列重排或统一空白。`.gitattributes`对导入质量表禁用文本转换；不要对所有文件执行换行转换。更新数据表是一次可审查变更，保留旧文件版本与来源。

新临时工作使用 `tmp/build/<组件>/`、`tmp/tests/<测试组>/<运行标识>/`。真实计算使用 `runs/<体系能量模型>/<运行标识>/`。tests目录仅放测试代码与fixtures，不放测试运行目录。根目录的.gitignore只是防误提交，发布前仍应检查git ls-files；已经跟踪的文件不会因为后来添加忽略规则而自动消失。

v0.1.0从原研究工作区筛选得到，未导入3.5GiB历史轨迹。历史实验脚本不在本公开仓库中伪装成开箱即用的工具。保留的旧Fortran说明属于阅读资料，当前流程、默认值和支持边界以根README与docs新手册为准。
